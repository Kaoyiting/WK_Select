# 架構與部署

> 專案目錄與部署說明｜2026-11-07。應用程式目前位於此 Git repository 根目錄。

## 範圍與架構

React + TypeScript + Vite 負責前台及管理後台；FastAPI 模組化單體處理 API；SQLAlchemy + Alembic 管理 PostgreSQL。Caddy 提供靜態頁面、同網域 API 反向代理及正式環境 HTTPS。先維持一份 compose.yaml，不引入 Kubernetes、微服務、Redis 或多租戶管理。

原始 public、worker、drizzle、scripts、.openai、dist 不修改。新版複製原有樣式及資產，保持原站畫面與 hash 路由；會員及結帳依已確認需求另行實作。尚未切換原站網域。

## Docker 與環境

compose.yaml 包含 web、api、db 三個服務；db/API 不開放主機連接埠。預設只綁 127.0.0.1:8089，避免本機測試直接公開。資料庫、上傳圖片、Caddy 憑證使用具名 volume；容器重建不應清除 volume。禁止用 down -v 當作一般更新方式。

開發、測試與正式環境各自使用獨立資料庫、圖片空間、環境檔及 OAuth 設定。自動測試只允許 *_test 資料庫。正式環境不能使用本機產生的帳密或測試資料。

| 變數 | 用途 |
|---|---|
| APP_ENV | local 或 production |
| DB_PASSWORD / DB_ADMIN_PASSWORD | 分離應用程式角色與 migration 管理角色 |
| SESSION_SECRET | 至少 32 字元隨機密鑰，不能提交 Git |
| PUBLIC_ORIGIN | 唯一允許來源；正式為 HTTPS 網址 |
| GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET | 會員 Google OAuth；callback 為 /api/v1/auth/google/callback |
| STORAGE_BACKEND | 本機 local；正式 r2 |
| R2_ENDPOINT_URL / R2_BUCKET / R2_ACCESS_KEY_ID / R2_SECRET_ACCESS_KEY | 私有圖片儲存；透過受控圖片路徑提供 |
| SITE_HOST | Caddy 網域，本機 :80 |
| WEB_BIND / WEB_PORT / TLS_BIND / TLS_PORT | 本機預設 loopback；正式需配置主機防火牆與 80/443 |

CKEditor 授權金鑰由後台設定，不包含在公開內容 API。未設定時顯示唯讀預覽，不以未授權編輯器代替。Google 未設定時拒絕會員登入，不提供假會員登入入口。

## 本機啟動與更新

在 repository 根目錄執行 `python scripts/setup_local.py`。這會產生被忽略的本機設定、建立容器、執行 migrations，僅在空資料庫匯入初始商品及建立兩個管理帳號。帳密位於本機 `.secrets/`；不要提交或公開。

一般更新：先備份、建置 image、使用 migration 管理連線執行 `alembic upgrade head`、`docker compose up -d --wait`。migration 連線只掛載給一次性容器，不提供給常駐 API。實際命令與復原流程見 README。

## 雲端上線順序

1. 選定雲端主機、網域與備份位置；一期一台 Docker 主機可起步。規格與費用待選定供應商後量測，不預先承諾容量。
2. 建立獨立正式秘密、Google OAuth 憑證、R2 儲存空間；確認網域與 callback；設定 HTTPS、防火牆及管理主機存取。
3. 建置並標記版本 image；驗證 compose 設定、migration、健康檢查；不匯入測試訂單或本機管理密碼。
4. 測試站完成手機/桌機、會員、圖片、訂單、運費、庫存、備份還原及金流驗證；正式金流未串接時不得宣稱能刷卡付款。
5. 設定錯誤/可用性/磁碟監控、日誌輪替、排程備份與異地保存；確認還原窗口和負責人。
6. 使用者驗收後另行確認切站與 DNS；保留原站復原方式。發版失敗先停寫入，再判斷回滾程式或以備份還原，禁止盲目降版資料庫。

## 2026-10-29 測試金流工作程序
compose.yaml 增加 payment-worker，同一後端映像執行 python -m app.modules.payments.worker，每 60 秒檢查到期 ATM 測試訂單。容器需持續運行，電腦／Docker 關閉時不執行；重啟後補掃到期訂單。處理失敗 rollback、記錄警告並於後續掃描重試。

ECPAY_ORDER_TESTING_ENABLED 與 ECPAY_SANDBOX_ENABLED 必須都為 true、APP_ENV 非 production，才開放 ATM 訂單測試。ECPAY_SANDBOX_CALLBACK_ORIGIN 指向公開 HTTPS origin。保持既有 PUBLIC_ORIGIN／Google OAuth 設定不變；從原瀏覽來源返回會員中心。Cloudflare 臨時通道更換後須更新通知 origin，新建交易再測試。

正式金鑰、正式收款與正式排程配置尚未開放；此版不能以移除測試旗標方式直接上線收款。
